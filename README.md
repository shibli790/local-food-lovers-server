# Local Food Lovers Network — Server

Express + MongoDB + Firebase Admin backend for the **Local Food Lovers Network**.

## Features
- Reviews CRUD with owner checks
- Favorites system (separate collection)
- Featured reviews (top-rated, limit 6)
- Search by food name using MongoDB `$regex`
- Firebase ID Token auth middleware
- CORS allowlist, Helmet, Morgan
- Vercel-ready, single-file `index.js`

 

## Run
```bash
npm i
npm run dev
```
